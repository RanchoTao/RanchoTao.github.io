# ranchotao.com

Source of [ranchotao.com](https://ranchotao.com), the personal homepage of Shengye (Rancho) Tao — research, projects, CV and writing.

Built with Jekyll on the [academicpages](https://github.com/academicpages/academicpages.github.io) template (MIT, see [LICENSE](LICENSE)) and deployed by GitHub Pages.

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```
